## 📖 About

Frontend built with **Next.js (App Router)** and TypeScript for quick
prototyping. Ships with ESLint and PostCSS already configured.

## ✨ Features

- Next.js 15 App Router
- TypeScript out of the box
- Tailwind-ready PostCSS setup

## 🚀 Getting Started

```bash
git clone https://github.com/Luis321123/fast-test-frontend.git
cd fast-test-frontend && npm install
npm run dev
```
